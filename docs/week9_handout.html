HPG 6104 • Week 9

Modern Methods in Epidemiology

Machine Learning, Prediction vs Causal Models, ML Cautions

01

The Great Divide: Prediction vs Causal Models

The most frequent category error in modern epidemiology is framing a prediction analysis, running a machine learning algorithm, and then drawing causal conclusions in the discussion section.

Prediction Models

"Who will develop the outcome?"

Concerned with association. Any variable that carries information about the outcome improves the model.

  • Goal: Minimise error on new data
  • Methods: Random Forest, XGBoost
  • Metrics: AUC-ROC, Brier Score, F1

Causal Models

"What happens if we change X?"

Concerned with intervention. We want to isolate the specific effect of an exposure on an outcome.

  • Goal: Unbiased effect estimate
  • Methods: G-computation, IPTW, TMLE
  • Metrics: ATE, Adjusted OR, 95% CI
02

The 5 Machine Learning Cautions

1. Overfitting

The model memorises training noise and fails on new data. A massive drop between training AUC (0.95) and validation AUC (0.70) is the classic red flag.

2. Confounding in Observational ML (Confounding by Indication)

ML models often show treatments (like statins or insulin) as highly predictive of bad outcomes. Why? Because only the sickest patients get the intensive drugs. A naive model learns this confounded association.

3. Algorithmic Bias

Models trained on historically biased data perpetuate those biases (e.g., pulse oximeters misreading on dark skin tones leading to delayed COVID-19 care for African populations).

4. Temporal & Distributional Shift

Model performance decays over time as guidelines or disease patterns change. An ML model requires a continuous monitoring and retraining plan.

5. SHAP values ≠ Causal Effects

SHAP values provide predictive explanations (why the model guessed what it did). They are NOT causal effect estimates and cannot be used to plan public health interventions.

03

Integrating ML and Causal Inference

We can use ML's flexibility to improve causal estimation while keeping the rigour of causal DAGs.

  • Double Machine Learning (DML): Uses ML to non-parametrically estimate nuisance functions (exposure probability and outcome probability), then isolates the causal effect of X on Y from the residuals. Prevents regularisation bias.
  • Targeted Maximum Likelihood Estimation (TMLE): A doubly-robust method. Uses ensemble ML (Super Learner) for initial estimates, then updates it to yield consistent ATE estimates.
  • Causal Forests: Extends random forests to estimate Heterogeneous Treatment Effects (CATE). Useful for Precision Public Health (finding which subgroups benefit most from an intervention).
